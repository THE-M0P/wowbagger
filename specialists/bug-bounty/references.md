# Research References

Checked on 2026-08-25.

## Benchmarks And Agent Designs

- BountyBench: real-world bug bounty benchmark with detect, exploit, and patch phases.
  https://github.com/EnvCommons/BountyBench
- BountyBench paper: dollar-impact benchmark over real systems and OWASP categories.
  https://arxiv.org/abs/2505.15216
- Project Naptime: hypothesis-driven vulnerability research with code browsing, terminal, debugger, and reporting tools.
  https://projectzero.google/2024/06/project-naptime.html
- EnIGMA: interactive terminal/debugger/server tools improve cybersecurity agent performance; warns about hallucinated observations.
  https://arxiv.org/abs/2409.16165
- PentestGPT: separates reasoning into penetration-testing submodules to reduce context-loss failures.
  https://arxiv.org/abs/2308.06782
- Cybench: task/environment/logging discipline for cyber agent evaluation.
  https://cybench.github.io/
